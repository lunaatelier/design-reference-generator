사용자 매뉴얼

각 입력 소스와 KPI별로 무엇을 넣고 어떻게 확인해야 하는지 설명합니다.

1. 자동 분석 입력 URL/문서/이미지 2. 디자인 보안 KPI Design 1.0 3. 기획 보안 KPI Planning 2.0 4. 수동 확인 항목 Human Review 5. 저장/보고 JSON/CSV

1. 자동 분석 입력 방법

URL, 문서, 이미지, 붙여넣기 텍스트를 입력하면 도구가 보안 위험 후보를 분석하고 KPI 입력값을 자동으로 채웁니다.

  • URL: CORS 허용 페이지는 직접 읽습니다. 실패 시 HTML/텍스트를 복사해 붙여넣습니다.
  • 문서: TXT, MD, HTML, CSV, JSON을 업로드합니다. PDF/DOCX는 텍스트 변환 후 붙여넣는 방식이 안전합니다.
  • 이미지: 파일명, 크기, 해상도, 스크린샷 여부를 분석합니다. 이미지 내부 텍스트는 사람이 직접 확인합니다.
  • 붙여넣기: 프롬프트 로그, RFP 일부, Figma 공유 정보, QA 리포트를 입력합니다.

2. 디자인 보안 KPI 사용법

디자인 자동화는 1.0 생성 단계이므로 기존 방식 대비 고도화 KPI는 제외하고 보안 KPI만 측정합니다.

  • 프롬프트 더미 데이터 적용률: 전체 프롬프트 중 sample, dummy, masked, 비식별 표현이 적용된 비율입니다.
  • 디자인 프롬프트 보안 위반 건수: 내부 URL, API Key, 고객명, 실제 데이터 후보를 확인합니다.
  • Figma 권한 점검 완료율: Figma 또는 Prototype 링크가 전체 공개 상태인지 확인하는 건수 지표입니다.
  • 비승인 저장소 Token 발견 건수: 개인 저장소, 외부 공개 저장소, 비승인 경로에 Token이 있는지 확인하는 건수 지표입니다.
  • QA 리포트 비식별화율: 저장된 QA 리포트 중 비식별화가 완료된 비율입니다.

3. 기획 보안 KPI 사용법

기획·설계 2.0은 RFP, 회의록, 요구사항, ui_spec, PRD, QA 시나리오의 보안 통제를 측정합니다.

  • 로컬 마스킹 적용률: 탐지된 민감정보 중 비식별화 완료 항목의 비율입니다.
  • 외부 API 전송 전 보안 통과율: 외부 AI/API 전송 대상 중 보안 Gate를 통과한 비율입니다.
  • SOURCE-REF 연결률: 전체 REQ-ID 중 원문 근거가 연결된 비율입니다.
  • 오염/할루시네이션 확정률: RFP 근거 없는 항목 후보의 비율입니다. 최종 판단은 사람이 확정합니다.
  • Repository 비식별화율: 저장소 항목 중 원문이 제거되고 비식별화된 항목의 비율입니다.

4. Human Review Queue 사용법

자동 분석이 어려운 항목은 사람이 직접 확인합니다. 필요 시 직접 항목을 추가하고 위험도를 지정합니다.

  • High: 고객명, 내부 URL, API Key, 원문 저장, 전체 공개 링크 등 즉시 확인이 필요한 항목입니다.
  • Medium: 이미지 캡처, Figma 권한, SOURCE-REF 누락 가능성, Repository 저장 항목입니다.
  • Low: 참고 검토 수준의 일반 확인 항목입니다.
  • 미확인 High Risk가 남아 있으면 제한 배포 판단을 보류합니다.

5. 저장 및 보고 방법

측정 결과는 JSON과 CSV로 저장할 수 있습니다.

  • JSON 저장: 다음에 다시 불러와 이어서 점검할 때 사용합니다.
  • CSV 내보내기: 엑셀 정리, 임원 보고, 제한 배포 판단 자료로 사용합니다.
  • 보고 기준: Pass/Warning/Fail뿐 아니라 Human Review 미확인 수와 High Risk 수를 함께 보고합니다.

자동 측정 입력 소스

아래 입력 소스를 분석해 KPI 값이 자동 채워집니다. 브라우저 보안 정책상 URL은 CORS가 허용된 경우만 직접 읽을 수 있으며, 실패 시 HTML/텍스트를 붙여넣으면 됩니다.

1. 사이트 URL 분석

웹페이지 HTML에서 내부 URL, IP, 이메일, 전화번호, API Key 패턴, 공개 링크 위험을 탐지합니다.

2. 문서 파일 분석

TXT/MD/HTML/CSV/JSON 문서를 분석해 Prompt, RFP, SOURCE-REF, 마스킹 여부, 보안 위반 후보를 탐지합니다.

3. 이미지 파일 분석

이미지 파일명, 크기, 해상도, 위험 키워드를 분석하고 미리보기를 제공합니다. 이미지 내부 텍스트 판독은 이 HTML 범위에서는 자동 판독하지 않으며 사람이 직접 확인합니다.

이미지를 드래그하거나 선택하세요.

4. 원문/로그 직접 붙여넣기

프롬프트 로그, RFP 일부, Figma 공유 정보, QA 리포트 내용을 붙여넣고 자동 분석합니다.
